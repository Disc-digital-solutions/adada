TO RUN THE WEBSITE ON YOUR COMPUTER (optional)

1. Install Node.js (the current LTS version) from nodejs.org
2. Open a terminal in the "web" folder
3. npm install            (in Windows PowerShell: npm.cmd install)
4. npm run dev            (in Windows PowerShell: npm.cmd run dev)
5. Open http://localhost:3240
